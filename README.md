Hi, I'm w31r4 — a developer focused on AI agents, currently an agent-backend engineering intern at [Converge AI](https://converge.ai/).

Mostly Go and Python, building agent systems end to end.

Open source is the part I love most — I hope to do it full-time one day. And I'm quietly waiting for the AI hype to cool off, so the engineering can speak for itself.

### What I've built

- A Go agent harness: turn loop, tool lifecycle, subagents, background tasks and interject.
- A permission / approval system that decides what an agent may run on its own.
- A Go sandbox runtime with macOS isolation, filtered network proxying and violation reporting.
- Bounded, cancellable tool I/O to keep agent context and token cost under control.
- An Office document runtime so agents can read and write DOCX / XLSX / PPTX / PDF.
- Agent integrations for IM / chat platforms, with outbound delivery exposed as a skill.
- An agent-behavior observability stack (OpenTelemetry) and a trace workbench.
- An AI gateway for model routing and access.
